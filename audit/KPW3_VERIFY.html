一、基础三验（验收 SOP）

  • 必验中文源：用中文界面打开一本含书签的书 → 进入「图库」→ 分段切换器可见「书签」文字标签；界面所有可见串为中文，无 ArtGallery_* 这类 gettext key 泄漏。
  • 必验切英文全英文：设置 → 语言切到 English → 重启 KOReader 后，插件自身界面串应尽可能全英文。
    已知现状：artgallery 是合并插件，目录内无 l10n 翻译文件（无 l10n/*.po），因此切英文后插件界面串仍多显示原始中文——这是合并插件的固有现状，非本次书签功能引入。验收时请区分：残留中文属于全插件 l10n 缺失，不计入书签功能缺陷；若某串在中文下就显示异常（如乱码/空白）才记为缺陷。
  • 必验框架串正常：分段切换器各段（全部 / 收藏 / 书签 / 忽略）标签、菜单项、按钮文案均正常显示，无未翻译 key、无 nil 文本、无方块乱码。

二、书签四点硬性要求（核心验收）

  • 要求①独立「书签N」段：打开有书签的书，分段切换器出现「书签」段且带计数（如「书签 3」）；该计数不并入「全部[N]」。
  • 要求①无书签时不可见：打开没有任何书签的书 → 分段切换器不应出现「书签」段（与忽略段同处理）。
  • 要求②书签永不进忽略池：长按书签缩略图 → 弹出菜单不出现「忽略图片」项（菜单含「跳转到此页」「收藏图片/取消收藏」「删除书签」）；无从把书签移入忽略段。
  • 要求③书签可收藏 + 收藏⭐角标：长按书签缩略图 → 菜单含「收藏图片」（可点击）、「取消收藏」（收藏后可用）；收藏后切到「收藏」段应能看到该书签项；「取消收藏」可正常移除。回到「书签（N）」池，已收藏的书签缩略图右下角应出现 ⭐（角点偏暗时自动反白，与「全部」视图一致）；未收藏则无 ⭐。
  • 要求④PNG 视作缓存可被清：先收藏/渲染若干书签 → 退出图库 → 图库「⋯」菜单「清除本书图片缓存」→ 确认书签缓存 PNG（位于 koreader/plugins/artgallery.koplugin/artgallery/bookmark_cache/）被清除，且本书书签收藏记录一并剔除（书签是缓存，非永久收藏）。
  • 交互轻点书签缩略图 = 全屏看图（glimpse 风 + 高清重渲染）：在「书签」段轻点任一缩略图 → 进入单图全屏态把该书签页当「伪图片」高清查看（初始以缩略图瞬时显示，随后异步拉取屏幕分辨率高清渲染替换；可缩放/切换全屏/三态填充）。跳转与删除放长按菜单：长按书签弹菜单含「跳转到此页」（一键回该书签名页，阅读器全屏呈现）、「收藏图片/取消收藏」（满足要求③）、「删除书签」（经二次确认从书本身移除该狗耳朵书签）；单图全屏态点 ⋮ 亦有「跳转到此页」。删除持久化：确认删除某书签后，该缩略图立即从「书签（N）」池消失；退出本书再重开，该书签仍不在（删除已即时落盘，不再从本书 .sdr 恢复）。

三、KPW3 墨水屏专项（流畅 / 稳定 / 续航 / 共存）

  • 流畅切到「书签」段时，缩略图异步渲染（委托 KOReader 内置 ReaderThumbnail 子进程，主线程仅读小 PNG）。首次进入允许短暂"占位→逐步填充"，不应卡死 UI 或触看门狗复位（约 200ms 以上阻塞应被拆离）。
  • 稳定反复进出图库、切换「全部↔书签↔收藏↔忽略」多轮后，无崩溃、无花屏、无触摸坐标偏移。
  • 稳定退出图库（关闭 viewer）后，书签内存缓存与在途渲染应释放——连续多次开关图库，设备内存（可用 RAM≈380MB）不应持续下降（用 /proc/meminfo 或 crash.log 中 OOM 痕迹佐证更佳）。
  • 续航书签功能默认 OFF（设置项「图库包含书签页」默认关）→ 不开此开关时零额外开销；开启后按需渲染，不常驻高 CPU、不频繁全刷空耗电。
  • 共存与设备上其他插件（coverbrowser、autoturn 等）同开时，图库交互、手势、刷新互不干扰；书签渲染不应抢占全局 gesture 或焦点。
