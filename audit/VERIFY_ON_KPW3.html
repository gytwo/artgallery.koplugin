美术馆 · KPW3 真机验证计划

artgallery.koplugin v1.0.0 — 阶段一至三已完成（headless 语法 + 核心逻辑单测通过）。本计划覆盖 headless 无法验证 的真机交互：LuaSettings 持久化、Archiver C 绑定（CBZ）、ConfirmBox UI、墨水屏刷新。

为什么需要真机验证？ 之前的 headless 测试只覆盖了纯 Lua 逻辑（scanner.scan_cbz 过滤/自然排序、迁移字节复制/碰撞后缀）。以下依赖 KOReader 运行时 C 绑定与 UI 事件，只能在 KPW3 上跑：收藏索引读写、CBZ 解包、迁移 ConfirmBox、全屏波形刷新。

一、部署前置

  1. 将 artgallery.koplugin 复制到设备的 koreader/plugins/ 目录。
  2. 移除 illustrations.koplugin 与 glimpse.koplugin（同名插件双装会产生重复菜单入口，且旧 Illustrations 的 Favorites/ 会被迁移逻辑探测到）。
  3. 完全退出并重启 KOReader（确保插件被重新加载）。
  4. （可选）保留 E:\Download\AIWorkshop\Backup\plugins\artgallery.koplugin\ 作为回滚源。

二、功能验证清单

能力操作路径预期行为crash.log 关注
① 全屏切换 ⤢ 打开含图书籍 → 调出 美术馆 抽屉 → 点 ⤢ 图标（或对应手势） 抽屉展开为全屏 panel_ratio=1.0，缩放/平移/旋转仍可用；再点收回复原抽屉宽度。 无 ArtGallery 报错
② 全局收藏 抽屉中 ⭐ 某图 → 退出书籍到文件管理器 → 菜单「收藏 → 显示收藏」 收藏画廊在无书本时也能打开（不崩）；缩略图来自 DataStorage:getDataDir()/artgallery/favorites/；长按可移除。 关注 showFavorites / _showExternalGallery
③ 旧收藏迁移 若设备曾有 Illustrations 且 <cache>/illustrations/Favorites/ 存在 → 首次「显示收藏」 弹 ConfirmBox「迁移 / 忽略」。迁移后旧图字节复制到 artgallery/favorites/ 并登记索引；忽略后不再打扰（LEGACY_MIGRATED_KEY）。 关注 _migrateLegacyFavorites / _offerLegacyMigration
④ GitHub 更新检查 菜单「更新」（继承 Glimpse，含预发布开关） 联网查询最新 release；无网络/无更新时优雅提示，不卡死。 关注网络异常分支
⑤ 最小尺寸过滤 设置中调整过滤级别（FILTER_KEY，继承） 低于阈值的图从画廊移除；阈值=0 时不过滤。 关注 scanner.filter
⑥ CBZ 浏览 文件管理器选中 *.cbz → 菜单「浏览 CBZ 漫画」 经 Archiver.Reader 解包到内存，按自然序逐页浏览；刻意不走 scanner.filter（漫画每页皆正文）。 关注 scanner.scan_cbz / Archiver
⑦ 作用域三态 抽屉 ⋯ → 切换作用域（全书 / 章节 / 当前页） 「当前页」仅显示已读到位置的图（剧透保护）；切换即时刷新画廊。 关注 _imagePage / on_toggle_scope

三、墨水屏（E-ink）专项

  • 刷新波形：全屏/切页应走 full 或 GC16 波形（干净非残影），抽屉内轻交互可用 UI 波形。
  • 点对点抖动：渐变/阴影（如抽屉投影）应抖动为点阵，避免灰阶拖影；可在设置关闭阴影（SHADOW_KEY）对比验证。
  • 响应与功耗：KPW3 CPU 受限，大图解码 + 全屏刷新应有可感知但可接受的延迟（<1s 为佳）；连续翻页不显著发热。

四、诊断与回滚

crash.log 排查（设备 koreader/crash.log）：

  • grep -i "美术馆" crash.log — 看插件级报错。
  • grep -n "stack traceback" crash.log — 定位崩溃栈。
  • 注意 LOG_TAG：插件日志若带 [ArtGallery] 可快速过滤。

回滚（出现异常时）：

  1. 删除 koreader/plugins/artgallery.koplugin。
  2. 从 E:\Download\AIWorkshop\Backup\plugins\artgallery.koplugin\ 取最近备份，或重装 glimpse.koplugin 恢复抽屉式体验。
  3. 重启 KOReader。
验证通过标准： 上述 7 项能力在 KPW3 上均可触发且行为符合「预期」列；crash.log 中无新增 ArtGallery 报错或 stack traceback。通过即代表 artgallery.koplugin v1.0.0 可发布。
